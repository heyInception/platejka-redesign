# Платёжка

Frontend-проект сайта [platejka.com](https://platejka.com/) на Gulp, SCSS и JavaScript с GSAP-анимациями.

## Начало работы

Требования: Node.js и npm.

```bash
git clone https://github.com/heyInception/platejka-redesign.git
cd platejka-redesign
npm install
npm run dev
```

Собранные файлы сохраняются в каталоге `app`.

## Команды

| Команда | Назначение |
| --- | --- |
| `npm run dev` | Запускает dev-сборку и BrowserSync. |
| `npm test` | Запускает автоматические тесты проекта. |
| `npm run build` | Создаёт оптимизированную production-сборку. |
| `npm run build:wordpress` | Собирает переносимые пакеты секций для WordPress. |
| `npm run backend` | Создаёт несжатую сборку для интеграции с backend. |
| `npm run cache` | Добавляет хеши к ассетам после production-сборки. |
| `npm run zip` | Упаковывает собранный проект в ZIP-архив. |
| `npm run html` | Проверяет HTML валидатором. |
| `npm run code` | Проверяет форматирование EditorConfig. |

## Сборка секций для WordPress

Команда `npm run build:wordpress` создаёт каталог `wordpress/`. Обычная команда
`npm run build` также запускает этот этап после сборки статических страниц в
`app/`.

```text
wordpress/
├── common/
│   ├── common.css
│   ├── common.js
│   └── fonts/
├── sections/
│   └── hero/
│       ├── hero.html
│       ├── hero-main.html
│       ├── hero.css
│       ├── hero.js
│       └── img/
└── manifest.json
```

В WordPress сначала подключаются `common/common.css` и `common/common.js`, затем
CSS и JS нужной секции из `manifest.json`. Имена файлов стабильны; версию для
`wp_enqueue_style()` и `wp_enqueue_script()` удобно получать через `filemtime()`.
Если поле `css` или `js` в манифесте равно `null`, пустой файл подключать не
нужно.

Новые компоненты добавляются в `sections.config.js`. Для компонента явно
указываются HTML-варианты, SCSS, один или несколько JS entry points и изображения.
Сборка завершится ошибкой, если объявленный исходный файл отсутствует либо HTML/CSS
ссылается на изображение, которого нет в списке `assets`. HTML остаётся
форматированным шаблоном: преобразование разметки в PHP и поля ACF выполняется на
стороне темы WordPress.

## Реализованные компоненты

### Шапка и навигация

- Desktop-навигация и полноэкранное мобильное меню для ширины `1024px` и меньше.
- Бургер размером `20 × 20px` с двумя линиями по `15px` и анимацией в крестик.
- Адаптивная трёхуровневая навигация с независимыми ссылками и кнопками раскрытия.
- На desktop меню открывается по наведению, фокусу и нажатию; на мобильных устройствах уровни работают как аккордеон.
- Мобильная панель имеет собственную прокрутку и блокирует прокрутку страницы.
- Закрытие по конечной ссылке, клику вне desktop-меню, клавише `Escape` и переходу на desktop-размер.
- Синхронизация `aria-expanded` и доступных подписей кнопок.
- GSAP-анимация панели, выпадающих пунктов и логотипа.
- Поддержка `prefers-reduced-motion`.
- Адаптивные стили подключены через миксины из `src/scss/mixins/_breakpoint.scss`.

### Прелоадер

- Полноэкранный фирменный прелоадер с логотипом.
- Восемь вертикальных секций заполняются попарно через GSAP.
- После заполнения запускается зелёная шторка и плавно появляется страница.
- Логотип в шапке изначально скрыт и анимируется только после завершения прелоадера, без вспышки конечного состояния.
- Повторный показ ограничен cookie `platejka-preloader-viewed`.
- Срок жизни cookie — 24 часа (`Max-Age=86400`, `Path=/`, `SameSite=Lax`).
- Если cookie недоступны, прелоадер продолжает работать без ошибки.
- При `prefers-reduced-motion: reduce` длительная анимация пропускается.

### Hero и калькулятор платежа

- Адаптивный Hero собран для desktop и mobile; контентная панель, изображение и blur анимируются через GSAP после события `platejka:ready`.
- Калькулятор поддерживает CNY и USD. При сумме меньше `3000` комиссия равна `275` единицам выбранной валюты, начиная с `3000` — `0,5%` от суммы.
- Курс конвертации и комиссия учитывают коэффициент `1.01`; кнопка расчёта открывает нативный `<dialog>` с итогами.
- Заголовок разделён на поля `.hero__title-primary` и `.hero__title-secondary`, поэтому цветную часть можно независимо заполнять из ACF.
- Фоновые изображения остаются в inline CSS-переменных `--hero-image` и `--hero-blur`, что позволяет выводить URL из WordPress без генерации отдельных CSS-классов.
- Курсы передаются в JSON-атрибуте `data-currency-rates`, например `{"CNY":12.3,"USD":81.0929}`. Перед выводом в WordPress значение нужно пропускать через `wp_json_encode()` и `esc_attr()`.

Рекомендуемые ACF-поля: `hero_title_primary`, `hero_title_secondary`, `hero_description`, `hero_background`, `hero_blur`, `hero_currency_rates`, карточки преимуществ и подписи калькулятора. Структуру HTML и `data-*`-атрибуты при интеграции следует сохранить — JavaScript не зависит от конкретных текстов.

### Калькулятор международного перевода

- Переиспользуемая секция подключена в `src/china.html` и повторяет desktop- и mobile-макеты Penpot; вертикальная компоновка начинается с `@include tablet`.
- Поддерживаются CNY, USD и EUR, форматированный ввод суммы, отправитель «Россия» и список стран получателя из WordPress-темы.
- Hero и отдельная секция используют одну модель расчёта и один контроллер в `src/js/components/hero.js`; каждый экземпляр хранит собственное состояние.
- Выбор страны оформлен через Select2: поиск включён для страны-получателя и отключён для единственного варианта отправителя. Без JavaScript остаётся рабочий нативный `<select>`.
- Анимированный индикатор валютных вкладок учитывает `prefers-reduced-motion`.
- Кнопка «Написать» открывает Telegram `platejka_com` с валютой, маршрутом и итогами расчёта.
- Кнопка «Отправить заявку» открывает локальный `<dialog>`. Контейнер `[data-cf7-mount]` подготовлен для вывода Contact Form 7, а поле `[data-cf7-summary]` может получить текст расчёта при интеграции.
- Значения в `data-currency-rates` демонстрационные. В WordPress атрибут должен формироваться сервером через `wp_json_encode()` и `esc_attr()`.

Разметка находится в `src/partials/calculator.html`, стили — в `src/scss/components/_calculator.scss`, общая модель — в `src/js/components/hero-calculator.cjs`, инициализация Select2 — в `src/js/components/calculator-select.js`.

### About

- Адаптивная секция о компании собрана по desktop- и mobile-макетам Figma.
- Каждый экземпляр `[data-about]` автономен: на одной странице можно размещать несколько секций без конфликтов селекторов и `id`.
- Карточки документов и ссылка на образец договора подготовлены для подключения реальных URL.
- CTA открывает собственный нативный `<dialog>` с закрытием по кнопке, клику на фон и `Escape`; после закрытия фокус возвращается на кнопку открытия.

Разметка находится в `src/partials/about.html`, стили — в `src/scss/components/_about.scss`, поведение — в `src/js/components/about.js`. Для переиспользования следует сохранять корневой атрибут `data-about` и вложенные `data-about-*`-атрибуты.

### Страница «О компании»

- Страница собирается из `src/about.html`; мобильная компоновка секций начинается с `@include tablet`.
- `about-hero` повторяет desktop- и mobile-макеты Figma, сохраняет контентную высоту карточек и запускает GSAP-анимацию после завершения прелоадера. SVG-подпись рисуется как линия от руки.
- `location` содержит контакты, фотослайдер и контейнер `#yamap` для Яндекс Карт. Карта инициализируется с адаптивным смещением метки; стрелки фотослайдера показываются от четырёх слайдов.
- `infrastructure` выводит специализации, факты и международную инфраструктуру компании. Флаги и графика находятся в `src/img/infrastructure/` и `src/img/destinations/`.
- `financial` содержит блок финансового комплаенса, кейс, список банков и предложение тестового платежа. Высота всех контентных карточек зависит от содержимого.
- `employees` оформлен как семантическая цитата сотрудника. Контент появляется один раз через GSAP ScrollTrigger, а SVG-подпись анимируется эффектом рисования пером.
- `exhibitions` — выходящий за контейнер четырёхслайдовый фотослайдер. Дополнительное конечное пространство трека позволяет отдельно открыть каждый слайд.
- `developing` показывает историю компании по годам. Количество дат не ограничено, каждая дата синхронизирована со своим слайдом, а стрелки отключаются при количестве слайдов меньше двух.
- `call-about` переиспользует основную форму и добавляет карточки прямых контактов и социальных сетей.
- Высота секций и текстовых контейнеров не фиксируется: макетные значения используются как `min-height` только там, где это необходимо для композиции.

Общая логика слайдеров находится в `src/js/components/horizontal-slider.js`, расчёты — в `src/js/components/horizontal-slider.cjs`. Анимации страницы подключаются из `src/js/components/about-hero.js` и `src/js/components/employees.js`, карта — из `src/js/components/location-map.js`.

### Shipments

- Адаптивная секция с шестью карточками сценариев поставок, собранная по desktop- и mobile-макетам Figma.
- На desktop используется сетка из двух колонок; начиная с breakpoint `@include tablet` карточки становятся горизонтальным слайдером шириной `280px`.
- Слайдер поддерживает свайп, перетаскивание мышью и переключение стрелками клавиатуры. После отпускания лента плавно фиксируется на ближайшей карточке через GSAP.
- Изображения карточек один раз появляются при входе секции в область просмотра через GSAP ScrollTrigger. При `prefers-reduced-motion: reduce` анимации отключаются.
- Карточки не содержат ссылок или кнопок; корневые `data-shipments` и `data-shipments-*`-атрибуты сохраняют контракт JavaScript-компонента.

Разметка находится в `src/partials/shipments.html`, стили — в `src/scss/components/_shipments.scss`, поведение — в `src/js/components/shipments.js`, а чистая функция расчёта позиции — в `src/js/components/shipments-slider.cjs`.

### Защита платежа и отзывы

- Обе секции подключены на странице `src/china.html`; мобильная компоновка начинается с `@include tablet` (`1024px` и меньше).
- «Защита платежа» показывает порядок действий при возврате, задержке и ошибке в реквизитах. Кнопка ведёт к секции документов; ссылку на конкретный пункт договора можно добавить после публикации файла.
- В «Отзывах» вкладки переключаются мышью и клавиатурой, включая `Home` и `End`. Видео- и текстовые отзывы представлены независимыми адаптивными слайдерами.
- Текстовые карточки имеют высоту по содержимому, отображают источник, автора и дату публикации.
- Первая карточка открывает тестовый MP4 в нативном `<dialog>`. Видео запускается при открытии, ставится на паузу и продолжает воспроизведение по нажатию на него. Во время загрузки показывается индикатор; стандартная панель управления скрыта.
- MP4 запрашивается только после открытия окна. При закрытии видео останавливается, источник удаляется, прокрутка страницы восстанавливается. Остальные карточки показывают состояние без видео до добавления файлов.
- Для новых отзывов укажите адрес файла в `data-review-video` соответствующей кнопки. Сборка копирует файлы `.mp4` из `src/img/` в `app/img/` без обработки изображения.

Разметка находится в `src/partials/protection.html` и `src/partials/review.html`, стили — в одноимённых файлах `src/scss/components/`, поведение отзывов — в `src/js/components/review.js`.

### Как мы работаем и какие проблемы мы решаем

- Секции подключены на странице `src/china.html` и свёрстаны по desktop- и mobile-макетам Penpot. Мобильная компоновка начинается с `@include tablet`.
- В секции «Как мы работаем» карточки документов и шаги процесса расположены в двух колонках на desktop и последовательно на мобильных экранах. Ссылка «Начать с расчёта» ведёт к калькулятору.
- В секции «Какие проблемы мы решаем» три карточки образуют сетку на desktop и слайдер без экранных стрелок на мобильных экранах. Свайп и клавиши со стрелками перемещают карточки через GSAP; учитывается `prefers-reduced-motion`.
- Кнопка «Отправить инвойс на разбор» открывает нативный `<dialog>` с закрытием по кнопке, фону и `Escape`. Фокус возвращается на кнопку открытия. Пока форма отправки не подключена, окно содержит поясняющий текст.
- «Написать» пока открывает `mailto:a@platejka.com`; иконка Telegram сохранена по макету. После получения адреса Telegram нужно заменить `href` в `src/partials/problems.html`.

Разметка — `src/partials/work.html` и `src/partials/problems.html`, стили — `src/scss/components/_work.scss` и `src/scss/components/_problems.scss`, поведение слайдера и окна — `src/js/components/problems.js`.

### Раскрывающийся SEO-контент

- Переиспользуемая секция подключается через корневой атрибут `data-seo`; на одной странице можно инициализировать несколько независимых экземпляров.
- До раскрытия остаются видимыми первый `h2` и следующий за ним абзац. Остальной контент JavaScript помещает во внутренний контейнер и скрывает.
- Кнопка плавно раскрывает и сворачивает контент, меняет подписи «Показать ещё» и «Скрыть» и синхронизирует `aria-expanded`.
- При `prefers-reduced-motion: reduce` переход выполняется без анимации.
- Без JavaScript весь текст остаётся доступен, а скрытая кнопка не отображается.

Разметка находится в `src/partials/seo.html`, инициализация — в `src/js/components/seo.js`, логика компонента — в `src/js/components/seo.cjs`, стили — в `src/scss/components/_seo.scss`. Для сохранения поведения нужны атрибуты `data-seo`, `data-seo-content` и `data-seo-toggle`.

### FAQ

- Переиспользуемая секция подключена в `src/china.html` и повторяет desktop- и mobile-макеты Penpot; вертикальная компоновка начинается с `@include tablet`.
- Семь пунктов оформлены доступными кнопками с `aria-expanded` и `aria-controls`. Второй пункт раскрыт при загрузке, одновременно может быть открыт только один ответ, повторный клик закрывает его.

### Call

- Переиспользуемая секция обратной связи подключена в `src/china.html` и повторяет desktop- и mobile-макеты Penpot. Вертикальная мобильная компоновка начинается с `@include tablet`.
- Форма содержит телефон, email, сообщение и обязательное согласие с политикой конфиденциальности. До подключения backend отправка отменяется без перехода страницы.
- Глобальная маска применяется ко всем полям `input.js-phone-mask` и использует формат `+7 (999) 999-99-99`. Повторная инициализация одного поля исключена.
- Заголовок, карточки преимуществ и форма один раз появляются при входе секции в область просмотра через GSAP ScrollTrigger.
- `gsap.matchMedia()` отслеживает `prefers-reduced-motion`: при включённом сокращении движения контент показывается без анимации.
- Каждый экземпляр `[data-call]` инициализируется независимо, поэтому partial можно подключать на других страницах без привязки к текстовому содержимому.

Разметка находится в `src/partials/call.html`, стили — в `src/scss/components/_call.scss`, инициализация — в `src/js/components/call.js`, тестируемая логика анимации и формы — в `src/js/components/call-motion.cjs`, глобальная маска — в `src/js/components/phone-mask.js` и `src/js/components/phone-mask.cjs`.

- Footer подключён после основного содержимого `src/china.html` и повторяет desktop- и mobile-макеты Penpot.
- В разметке используются семантические `<footer>`, `<address>` и три навигационных блока для разделов «Информация», «Услуги» и «Новости».
- Desktop-версия имеет четырёхколоночную компоновку, скругление `40px` и высоту макета `692px`.
- Начиная с `@include tablet` контент выстраивается в одну колонку, скругление снимается, а вертикальные интервалы соответствуют мобильному макету высотой `1586px`.
- Контакты, реквизиты, отметка о реестре ЦБ, логотип, служебные ссылки и юридические уведомления собраны в отдельные смысловые группы.
- Все ссылки Footer временно ведут на `#`; при интеграции следует заменить их реальными адресами.

Разметка находится в `src/partials/footer.html`, стили — в `src/scss/components/_footer.scss`, логотип и иконки — в `src/img/`, проверки контента и адаптивной структуры — в `tests/footer-section.test.cjs`.

### UI-kit

В глобальных стилях доступны базовые компоненты и состояния:

- кнопки `.ui-button` размеров `medium` и `small`;
- варианты кнопок `secondary` и `overlay`;

## Интеграция главной страницы с WordPress

Для трёх переиспользуемых секций предусмотрены независимые ACF Select-поля: `shipments_mode`, `guarantees_mode` и `documents_mode`. Каждое поле принимает значения `default` и `main`; пустое, неизвестное или отсутствующее значение должно безопасно возвращать вариант `default`.

При переносе partials в PHP необходимо сохранить корневые и вложенные `data-*`-атрибуты: они являются контрактом JavaScript-компонентов. Контент, ссылки и изображения можно выводить из ACF независимо от выбранного режима. В секции финансового комплаенса контейнер `[data-cf7-mount]` предназначен для шорткода Contact Form 7; статическая сборка намеренно содержит только заглушку.

Главная страница `src/index.html` включает отдельные варианты Shipments, Guarantees и Documents, а также новые секции:

- `compliance.html` — финансовый комплаенс с нативным диалогом и местом для формы Contact Form 7;
- `review-main.html` — видео- и текстовые отзывы во вкладках, адаптивные слайдеры и модальное окно видео; стрелки на desktop появляются от 5 видео- или 4 текстовых отзывов, высота текстовых карточек зависит от контента;
- `with-us.html` — преимущества работы с сервисом;
- `destinations.html` — список стран с 10 элементами в начальном состоянии и GSAP-анимацией кнопки «Показать ещё» / «Скрыть»;
- `serves.html` — горизонтальный слайдер, визуально выходящий за границу основной сетки;
- `cases.html` — карточки кейсов;
- `table.html` — семантическая сравнительная таблица без ограничения высоты текста и с горизонтальной прокруткой на узких экранах.

Общая логика горизонтальных слайдеров находится в `src/js/components/horizontal-slider.js`, а тестируемые расчёты — в `src/js/components/horizontal-slider.cjs`. Мобильная компоновка новых секций начинается с breakpoint `@include tablet`.
